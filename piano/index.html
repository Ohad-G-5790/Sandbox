How to play

MIDI keyboard

Plug in any class-compliant USB or Bluetooth MIDI keyboard and click Connect MIDI. Key velocity, sustain, sostenuto and soft pedals all work. Works in Chrome, Edge, Opera and Firefox.

Computer keyboard

Two rows of white keys with the black keys above them, like a piano. Physical key positions are used, so any layout works.

Z–/ row: C3 – E4  ·  Q–] row: C4 – G5
Space sustain  ·  Shift accent  ·  ↑↓ dynamics  ·  ←→ octave  ·  Esc all notes off

Mouse, touch, pen

Hit a key near its front edge for a loud note and near the top for a soft one. Drag across keys for a glissando; multi-touch chords work. Pens use real pressure.

Piano samples: Salamander Grand Piano V3 by Alexander Holm, CC BY 3.0. Everything runs locally in your browser; nothing is uploaded.

Click, tap, or press any key to start

Browsers only start audio after a gesture. Your MIDI keyboard will be connected at the same time.
